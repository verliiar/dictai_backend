DictAI 

Backend DictAI - cерверная часть проекта DictAI - приложение автоматизирующее работу с аудиозаписями встреч и совещаний. Оно позволяет преобразовывать аудио в текст, определять участников разговора и получать структурированные результаты с кратким содержанием обсуждения.

О проекте

Backend реализован на основе микросервисной архитектуры. Обработка аудио разделена на несколько этапов: загрузка файла, распознавание речи, определение спикеров, формирование транскрипта и генерация итогового резюме.

Для взаимодействия сервисов используется NATS, а данные хранятся в PostgreSQL. Компоненты обработки речи и генерации текста интегрированы с AI-моделями.

Основной функционал

* Асинхронная обработка аудиозаписей
* Распознавание речи и определение спикеров
* Формирование транскриптов с временными метками
* Автоматическое создание резюме встреч
* Управление пользователями и рабочими пространствами
* Хранение результатов и доступ к ним через API

Технологии

Go - основная серверная логика
Python / WhisperX - распознавание речи
NATS - взаимодействие микросервисов
PostgreSQL - хранение данных
Docker - контейнеризация и запуск сервисов

Локальный запуск

Для запуска необходимы Docker и Docker Compose.

cd infra
cp .env.example .env
docker compose up -d

Перед запуском необходимо настроить переменные окружения в .env.
